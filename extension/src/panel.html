Step 1 — learn the unsend request

Open a Messenger chat, hover a message of your own, choose Remove → Remove for everyone and confirm. This page then records the exact GraphQL recipe Meta used, so the bulk job can repeat it without clicking the UI. Nothing is deleted by this step except that one message you removed by hand.

Captured operations

Look for an entry whose name or variables mention a message id (message_id, messageId, mid.$). That is the unsend mutation.

Step 2 — replay console (recon)

Send one captured operation with edited variables. Use this to check whether the server still accepts an unsend for an old message, and to see the raw response. Requests go from your own logged-in tab.
